## 使用方法

### 查看地图
1. 在浏览器中打开 `周年庆打卡地图.html` 文件
2. 可以看到完整的交互式打卡地图
3. 点击右上角的"下载地图"按钮获取使用说明

### 转换为PNG
如果需要PNG格式，可以：

1. **使用在线工具**:
   - 访问 https://convertio.co/ppm-png/
   - 上传 `周年庆打卡地图.ppm` 文件
   - 下载转换后的PNG文件

2. **使用图像处理软件**:
   - GIMP (免费)
   - Photoshop
   - 其他支持PPM格式的软件

3. **使用命令行工具** (如果系统已安装):
   ```bash
   convert 周年庆打卡地图.ppm 周年庆打卡地图.png
   ```
