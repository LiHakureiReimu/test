# 🎉 周年庆打卡地图

一个具有科技感风格的周年庆活动打卡地图，支持5个打卡地点的进度跟踪和印章收集。

## ✨ 功能特点

- **科技感设计**: 采用深色主题配合青色发光效果，营造未来科技氛围
- **响应式布局**: 支持各种设备尺寸，移动端友好
- **交互式打卡**: 点击打卡地点即可完成打卡，支持印章效果
- **进度跟踪**: 实时显示打卡进度条和完成数量
- **本地存储**: 自动保存打卡进度，刷新页面不丢失
- **键盘快捷键**: 支持数字键1-5快速打卡，R键重置进度
- **庆祝效果**: 完成所有打卡后触发庆祝动画

## 🗺️ 打卡地点

1. **🎮 粘币游戏** - 游戏互动体验
2. **🛍️ 淘趣循环市集** - 市集购物体验
3. **📸 框住时光·与你同行** - 拍照留念活动
4. **❓ 快问快答** - 知识问答挑战
5. **🔮 量子纠缠瓶** - 神秘体验活动

## 🚀 使用方法

### 基本操作
1. 打开 `index.html` 文件
2. 点击任意打卡地点卡片进行打卡
3. 确认完成后，印章区域会显示完成状态
4. 查看进度条了解整体完成情况

### 快捷键
- **数字键 1-5**: 快速选择对应打卡地点
- **R键**: 重置所有打卡进度

### 印章区域
每个打卡地点都预留了专门的盖章区域，工作人员可以在完成活动后在此区域盖章确认。

## 🎯 自定义配置

可以通过修改CSS变量来调整主题色彩：

```css
:root {
    --primary-color: #00ffff;      /* 主色调 */
    --secondary-color: #ff00ff;    /* 次要色调 */
    --background-dark: #0c0c0c;    /* 深色背景 */
    --accent-color: #00ff00;       /* 强调色 */
}
```
